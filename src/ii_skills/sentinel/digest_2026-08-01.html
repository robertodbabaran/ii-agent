Top 5 Headlines

1. Claude Opus 5 ships — 96% SWE-bench, same Opus price

Released July 24, Opus 5 posts 96.0% on SWE-bench Verified and 79.2% on SWE-bench Pro — double its predecessor's agentic coding capability — at unchanged Opus pricing. It ships with a 1M-token context, adaptive thinking on by default, and a five-level effort toggle, making it the go-to model for long-running autonomous tasks in Claude Code.

2. MCP 2026-07-28: stateless core, serverless deployment unlocked

The largest MCP spec change since launch drops the initialize handshake and session ID entirely — a single HTTP request is now a complete, self-contained tool call. Three official extensions ship under a versioned framework: MCP Apps (server-rendered UI), Tasks (async long-running ops), and Enterprise Managed Auth (Entra / Okta IdP provisioning). Monthly SDK downloads: 400 M, up 4× year-to-date.

3. Lilian Weng's "Harness Engineering for Self-Improvement" (July 4)

The most-cited AI post of July argues that recursive self-improvement starts not with weights but with the harness: the orchestration layer managing tool calls, planning loops, memory, sub-agent delegation, and evaluation. Synthesises 35 papers; endorsed by DeepSeek's Cui Tianyi. Framing AI engineering as harness design has reshaped how practitioners at AIEWF 2026 described their work.

4. Claude Cowork goes web and mobile (August 3 beta)

Cowork sessions now run in Anthropic's cloud on iOS, Android, and the web app, with cross-device file sync and background task continuity. Team and Enterprise plans included. Doubled usage limits extended through August 5. Shared artifacts (not sessions) are sharable org-wide.

5. AI Engineer World's Fair 2026: 6,000 engineers, one theme — loops and harnesses

The conference (Latent Space recap: "5 Trends That Defined AIEWF 2026") crowned loop engineering and harness discipline as the defining practices. The opening keynote was titled "Loopcraft: The Art of Stacking Loops." The field has moved from "build an agent" to "engineer the system around the agent."

Architecture Watch
Pattern: Stateless MCP Over Serverless

With the 2026-07-28 spec, MCP tool calls become plain HTTP requests — no sticky sessions, no shared session stores, no specialist infrastructure. This is a direct unlock for ii-agent skills that currently need persistent connections: any MCP server can now deploy on Lambda, Cloudflare Workers, or Cloud Run, behind an ordinary load balancer. AWS AgentCore Gateway already supports the new spec.

Pattern: Harness-First Agent Design

Weng's framing crystallises a trend: the harness (workflow orchestration, context windows, eval loops, memory, budgeting) matters as much as the model. ii-agent's sentinel/newsletter skills are already harness-first; the insight is to make that structure explicit and self-improving — e.g., letting evals feed back into prompt templates and scheduling decisions.

Pattern: Graph + Vector Memory Hybrid

Graph memory graduated from experimental to production in early 2026; 13 frameworks now support it. The production consensus is graph memory (entity relationships) + vector memory (semantic similarity) — neither alone is sufficient. For deal_memory in ii-agent, adding a lightweight graph layer over existing vector retrieval would improve cross-deal entity recall.

Capability Spotlight
MCP Tasks Extension (Official)

The Tasks extension in MCP 2026-07-28 formalises async long-running operations — exactly what ii-agent's newsletter and sentinel scripts need. Servers can now declare a task, return a task ID immediately, and stream progress. This replaces the current pattern of running Python scripts in the background and hoping they complete.

Claude Opus 5 Effort Toggle (5 Levels)

Opus 5 ships a five-level effort setting, letting you trade latency and cost against reasoning depth per call. For ii-agent: use effort: low for market-price lookups in newsletters, effort: high for LBO model validation and IC prep. The Claude Code CLI surfaces this via the /effort command.

Amazon Bedrock AgentCore — Managed Web Search + Policy Controls GA

AgentCore added a fully managed web search tool (zero data egress, cited results) and moved policy controls to GA — precise action-level permissions verified outside the agent's reasoning loop. If ii-agent ever runs on AWS, these remove the need to build your own search + guardrail layer.

CrewAI v1.12 — Qdrant Edge Memory + Native OpenRouter Support

CrewAI now ships with Qdrant Edge as a memory backend (on-device vector store, no cloud required) and native support for OpenRouter, DeepSeek, Ollama, and Cerebras as drop-in providers. Relevant if ii-agent skills ever expand to multi-role crew workflows for deal analysis.

Workflow Ideas
Loop Stacking for Sentinel

The AIEWF "Loopcraft" framing suggests nesting loops by frequency: an outer weekly loop (Sentinel) feeds a daily briefing loop (market newsletter) which feeds an intra-day alert loop (price thresholds). ii-agent already has the skills; making the dependency chain explicit — each loop's output becomes the next loop's context — would tighten the whole system.

Eval-Driven Prompt Refinement

Weng's harness-for-self-improvement pattern applied concretely: after each Sentinel run, score the digest quality (coverage breadth, freshness, actionability) and write a short eval note back to the sentinel prompt. Over 4–6 weeks the prompt self-tunes. This is low-cost and directly in scope for a scheduled task running anyway.

MCP App for Deal Memory UI

MCP Apps (server-rendered UI, now an official extension) would let deal_memory surface a web UI directly inside Claude without any separate frontend. A thin FastAPI MCP server wrapping the existing DealMemory class could render deal notes, assumptions, and history as a formatted page inside the Claude chat.
