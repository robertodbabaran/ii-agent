Architecture Watch

MCP Goes Stateless — Production Infrastructure Pattern

The 2026-07-28 spec eliminates session stickiness entirely. MCP servers can now run behind standard round-robin load balancers — no more shared session stores or sticky routing. This transitions MCP from a "local dev tool" to a genuinely distributed protocol. Protocol metadata moves to _meta fields on individual requests. Any server using Mcp-Session-Id will need rearchitecting.

Microsoft Agent Framework Orchestration Patterns 1.0 (July 8)

Sequential, Concurrent, Group Chat, Handoff, and Magentic-One orchestration patterns reach 1.0 stability in both .NET and Python SDKs. All patterns support checkpointing, human-in-the-loop approvals, streaming, and pause/resume for long-running workflows. The Magentic-One pattern — give a goal + manager + specialists, let the manager self-organize the team — is the least hand-coded option and worth evaluating for complex ii-agent multi-skill workflows.

Lilian Weng: "Harness Engineering for Self-Improvement" (2026)

Former OpenAI researcher and Thinking Machines Lab co-founder published a landmark essay arguing the system surrounding the model is now as critical as the model itself: workflow management, context, permissions, evaluation, persistent state, and continuous self-improvement loops. The framing "harness engineering" is increasingly shared across AI engineering circles — relevant to how ii-agent structures its skill infrastructure.

Capability Spotlight

Live MCP Connectors in Claude Code Artifacts

Published Claude Code artifacts can now call MCP connectors on each viewer load — a dashboard shows live data rather than a snapshot from session time. Each viewer uses their own credentials; access is approved on first load. For ii-agent, this means the net worth dashboard or health metrics artifact could display real-time data without needing a re-run session. Massive upgrade for anything built as a persistent artifact.

MCP SDK Betas — Python, TypeScript, Go, C# (2026-07-28 Spec)

Beta SDK releases are live now at blog.modelcontextprotocol.io. If ii-agent integrates any MCP servers, testing against the beta SDKs now will prevent a migration scramble when the final spec ships July 28. Key breaking changes: no initialize handshake, no session headers, new required Mcp-Method + Mcp-Name headers.

AgentCore CLI v0.4.0 GA (AWS)

AWS's AgentCore reaches GA with managed session storage (1GB per session, 14-day retention, standard Linux filesystem), Chrome Enterprise policies, custom root CA cert support, and multi-framework support for Google ADK + OpenAI Agents SDK. Useful for any ii-agent skills that need cloud-hosted persistent execution rather than local runs.

Safari MCP Server (Apple, July 1)

Safari Technology Preview 247 ships a built-in MCP server that lets AI agents emulate user web experiences — useful for web automation, debugging, and testing tasks. Agents can now inspect real browser rendering through a standards-based protocol rather than headless workarounds.

Workflow Ideas for ii-agent

Nested Subagents for Multi-Phase IB Workflows

Claude Code now supports 3-level subagent nesting. Apply this to the IB Toolkit: a top-level orchestrator spawns an LBO analyst subagent (which itself spawns tool-specific sub-agents for data pulling and formula building). Currently the IB Toolkit runs in a single agent loop — depth-3 nesting would allow parallel model-building sub-threads with isolated context windows.

Plan-and-Execute for Cost Efficiency (40-60% savings)

Teams winning with workflow agents in 2026 are using a two-tier model: a planner (cheaper model — Haiku-class) that breaks down the task, and an executor (smarter model) that carries out each step. For ii-agent's daily newsletters and routine data-fetching skills, routing the planning phase through a lightweight model could meaningfully reduce per-run costs.

Prompt Versioning as Production Artifacts

The ii-agent PROMPT_LIBRARY.md is already a good start. The 2026 production AI playbook goes further: prompts are versioned in git, tagged with model+performance metadata, and tested against evals before updates ship. Consider adding a prompt changelog workflow — when a skill prompt is changed, it gets a version bump and a quick benchmark run before going into production.

OpenWiki: Auto-Generate AI-Friendly Codebase Docs

OpenWiki (from the LangChain team, one of the trending GitHub repos this week) is a CLI that automatically generates and maintains AI-readable documentation for your codebase. Given ii-agent's growing CAPABILITIES.md and CLAUDE.md structure, this could keep the skill documentation in sync with code changes automatically.
