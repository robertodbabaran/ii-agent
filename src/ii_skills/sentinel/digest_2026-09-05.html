Top 5 Headlines
01  ·  Anthropic
Claude Fable 5.1 ships with 1M-token context and 75% cheaper cache reads

Released September 1, Fable 5.1 (and its gated sibling Mythos 5.1) is now the default Fable model in Claude Code. The 75% drop in cache-read pricing materially lowers the operating cost of long-running agent workflows and multi-hour sessions — directly beneficial to ii-agent's scheduled newsletter tasks. Watermarking and C2PA Content Credentials are enabled on all generated text and media.

02  ·  Claude Code / MCP
Claude Code v2.1.259 introduces managedMcpServers — centralized org-wide MCP deployment

Shipped September 2. Organizations can now push HTTP and SSE MCP servers to every user automatically via a managedMcpServers key in their Claude Code org settings — the same shape as .mcp.json, but applied org-wide without per-user configuration. This is the most impactful ii-agent infrastructure change this week.

03  ·  Security
Anthropic Inference Hooks enter Enterprise beta — inline DLP before every prompt

Every prompt and tool-call response now routes through a signed WebSocket to your security server before reaching Claude. Your server returns allow/deny; Claude enforces in real time. Works across Claude Enterprise, Claude Code, Cowork, and MCP connectors. Plugs into Zscaler, Palo Alto, Netskope, and Proofpoint out of the box — a significant milestone for enterprise AI governance.

Architecture Watch
Pattern
Supervisor / Orchestrator — the dominant production multi-agent pattern

The field has converged: one orchestrator agent (using a capable/expensive model) receives the task, breaks it into subtasks, and delegates to specialist workers (using cheaper, task-specific models). Teams report 40–60% cost reduction versus homogeneous fleets. Microsoft's WorkflowBuilder formalizes this as a compile-time type-safe directed graph with sequential, parallel, conditional, and handoff patterns.

Protocol
MCP 2026-07-28 Release Candidate — stateless HTTP, Tasks extension, MCP Apps

The largest MCP protocol revision since launch delivers a stateless core that runs behind plain round-robin load balancers (no sticky sessions), a Tasks extension for long-running work with pause/resume, and MCP Apps for server-rendered UIs. List and resource results now carry cache-control metadata. 200+ servers in the ecosystem, growing weekly.

Infrastructure
AWS Agent Registry GA — auto-discovers agents across AWS Organizations

AWS Agent Registry is now generally available, auto-detecting AgentCore Runtimes and Gateways across member accounts into a single unified registry. AgentCore Evaluations now covers TypeScript frameworks (Strands, LangGraph, OpenAI Agents, Vercel AI SDK) alongside Python, and added support for Claude Agent SDK, LlamaIndex, and Google ADK evaluation targets.

Capability Spotlight
Claude Code Feature
managedMcpServers — org-wide MCP distribution

Add an HTTP/SSE MCP server once in your org's Claude Code settings and it propagates to all users automatically. Eliminates per-user .mcp.json drift. This is the right primitive for ii-agent: central skill/tool governance without manual per-session config.

Anthropic Enterprise
Inference Hooks — WebSocket DLP gateway for all Claude surfaces

Even for personal/solo use, inference hooks expose a powerful pattern: a sidecar process that inspects and can modify every Claude inference request. Could be repurposed for audit logging, cost throttling, or context injection beyond DLP — worth watching for ii-agent's governance layer.

MCP Ecosystem
Enterprise platforms adopt MCP natively — SnapLogic, Workato, MuleSoft

All three major enterprise iPaaS platforms shipped production MCP support this cycle. Combined with the new stateless HTTP transport in the 2026-07-28 RC, MCP servers can now sit behind standard cloud load balancers — opening the door to highly available, scalable tool endpoints for ii-agent skill modules.

Workflow Ideas
Orchestration Pattern
Debate/Council pattern for high-stakes analysis

Two agents independently answer the same IB/IR analysis prompt, then a judge model selects and synthesizes the stronger output. Well-suited for QoE challenges, LBO sensitivity debates, and IC prep where the second opinion matters. Add to ib_toolkit as an optional multi-agent review step.

Cost Optimization
Fable 5.1 cache-read pricing — restructure scheduled tasks around caching

At $0.25/M cache-read tokens (75% below input price), it's now cheap to inject large context — sector playbooks, case notes, reference templates — as cached system context rather than recomputing each turn. Sentinel, market newsletter, and IB toolkit all benefit from pre-warmed context blocks.

Security / Governance
Local inference hook pattern for ii-agent audit logging

Inference hooks use a signed WebSocket protocol with a documented schema. Even without Claude Enterprise, the pattern is instructive: a local sidecar that intercepts tool calls could enforce ii-agent's three-tier file protection rules (Tier 1/2 guard rails) automatically rather than relying on prompt-only instructions.

This Week's Recommendation

Adopt managedMcpServers to centralize ii-agent's MCP configuration. Claude Code v2.1.259 lets organizations push HTTP/SSE MCP servers to all users via a single settings key — eliminating per-session .mcp.json drift. For ii-agent, this means the Gmail MCP, GitHub MCP, and any future skill-endpoint MCP servers can be declared once in the org settings and automatically available in every scheduled and interactive session. This directly fixes the Gmail connector availability issue that affected this digest delivery.

Concretely: add a managedMcpServers block to your Claude Code org settings (or .mcp.json) pointing to the Gmail and other connectors you use, and set enabledInChat: true by default for scheduled sessions.
