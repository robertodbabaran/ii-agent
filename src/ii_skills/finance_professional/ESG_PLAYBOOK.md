## 1. Corporate Governance Scorecard — MOST COMMON

### ISS-Style Scoring (2017 Copa: 60.3/100)
| Category | Weight | What to Assess |
|----------|--------|----------------|
| Board of Directors | 30% | Independence, size, gender, separation of Chair/CEO |
| Transparency & Disclosure | 30% | Financial reporting quality, audit standards |
| Shareholders | 30% | Voting rights, ownership concentration, proxy access |
| Executive Compensation | 5% | Pay-for-performance, clawback, CEO pay ratio |
| Stakeholders-CSR | 5% | Community engagement, labor practices |

### DVFA-Adapted Scorecard (2018 Lausanne: 70/100)
Detailed 70-point framework adapted from German Financial Analysts Association (DVFA):
- Board composition and diversity
- Risk management and internal controls
- Executive remuneration structure
- Shareholder rights and takeover defense
- Related party transactions
- Audit committee composition

### Quick Governance Checklist
- [ ] Board independence ratio (target: >50% independent)
- [ ] Chair/CEO separation (best practice: separate)
- [ ] Board gender diversity (target: >30% female)
- [ ] Average board tenure (warning: >12 years)
- [ ] CEO compensation vs median employee (disclosure)
- [ ] Say-on-pay vote result (warning: <90% support)
- [ ] Insider ownership trend (bullish: buying)
- [ ] Free float % (liquidity risk if <50%)

## 3. Environmental Analysis Framework

### What to Cover
| Metric | Data Source | Best Practice |
|--------|------------|---------------|
| **Scope 1 emissions** | Sustainability report | Track trend, compare to peers |
| **Scope 2 emissions** | Sustainability report | Location-based AND market-based |
| **Scope 3 emissions** | CDP, estimates | If available; note if not disclosed |
| **Emissions intensity** | GHG / Revenue | Better than absolute (normalizes for growth) |
| **Net zero target** | Public commitment | Date + interim milestones |
| **Renewable energy %** | Sustainability report | Current + trajectory |
| **Carbon price exposure** | Regulation analysis | Quantify financial impact |
| **Green certifications** | BREEAM, LEED, EU Taxonomy | % of revenue qualifying |

### ESG Cost Escalation Model (2025 Kozminski)
Rather than adjusting beta for ESG (which is debatable), embed ESG costs in financial projections:
```
SG&A as % of Revenue: Base + 10bps per year (compliance cost escalation)
```
This is more defensible than ESG-adjusted WACC.

## 4. ESG-in-Valuation Integration Methods

### Three Approaches (2024 Cargojet — explicitly tested all three)

| Method | How | When |
|--------|-----|------|
| **Revenue adjustment** | ±5% revenue for ESG factors | Regulatory risk, green demand |
| **WACC adjustment** | ±50bps to discount rate | ESG risk premium / discount |
| **Multiple adjustment** | ±2x to exit multiple | ESG-driven multiple expansion |

### ESG Premium in Relative Valuation (2021 Vestas)
Applied ~10% premium to peer EV/EBITDA multiple for ESG leadership:
```
Peer median: 22x EV/EBITDA
ESG premium: +10% → 24x
Applied to EBITDA → higher target price
```

### ESG-Adjusted Beta (2025 Kozminski)
Sustainalytics provides beta adjustments:
```
Baseline beta: 1.00
Operating performance: -0.03
Financial flexibility: -0.02
Asset performance: -0.02
Regional corruption: +0.02
Carbon emissions: +0.02
= ESG-adjusted beta: 0.95
```

## Summary: ESG Integration Checklist for Any Case

### Quick Turnaround (30 min)
- [ ] Pull external ESG ratings (MSCI, Sustainalytics, Bloomberg)
- [ ] Check board diversity and independence
- [ ] Note any major ESG controversies
- [ ] State whether ESG adjustment to valuation is warranted (usually: no)

### Full Analysis (2+ hours)
- [ ] Build proprietary ESG scorecard (E/S/G dimensions, 0-5 scale)
- [ ] Benchmark against 3+ external rating agencies
- [ ] Compare ESG scores across peer set
- [ ] Quantify environmental metrics (Scope 1/2/3, intensity, targets)
- [ ] Assess governance using checklist (board, compensation, transparency)
- [ ] Test ESG valuation sensitivity (3 methods)
- [ ] Map SDG alignment (if applicable)
- [ ] Embed ESG compliance costs in financial projections
